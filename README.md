 E-Commerce Manual Testing Project

 Project Overview

Performed End-to-End Manual Testing on an E-Commerce Web Application. Created Test Plan, Test Scenarios, Test Cases, Requirement Traceability Matrix (RTM), Bug Reports, and Test Summary Report. Conducted Functional, Smoke, and Regression Testing to validate critical business workflows.

 Modules Tested

- User Registration
- User Login
- Product Search
- Product Details
- Shopping Cart
- Checkout
- Payment
- Order History

Testing Types Performed

- Functional Testing
- Smoke Testing
- Regression Testing
- Positive Testing
- Negative Testing

Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- RTM (Requirement Traceability Matrix)
- Bug Report
- Test Summary Report
- Test Execution Screenshots
